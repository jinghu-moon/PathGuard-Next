# Hide H0.1 shell-domain baseline: Xiaomi alioth

## 1. 结论

本次运行完成了 H0.1 的 ADB shell-domain 基线验证，探针和 JSONL
observation contract 工作正常，未出现 setup error，也未在设备留下测试沙箱或新增
mount table 记录。

本结果只能证明探针可用以及当前设备的 syscall/存储拓扑基线，不能证明目标 App
中的 `hide.direct_vfs`。H0.1 状态保持 **Conditional / In progress**，必须继续完成
debuggable app-domain、Java/NIO、JNI raw syscall、MediaStore 和选择器矩阵。

## 4. Direct VFS 基线

沙箱路径为：

```text
/data/local/tmp/pathguard-hide-h0-20260728-003113/hidden
```

在没有 hide backend 的基线状态下，以下访问均能观察到目标：

| 入口 | 沙箱目录 | 已知后代 | symlink alias |
|---|---:|---:|---:|
| `stat/lstat/access` | 可见 | 可见 | 可见 |
| `open/openat` | 成功 | 成功 | 成功 |
| `opendir` | 成功 | `ENOTDIR`（后代是文件） | 成功 |
| `fstatat/statx/faccessat` | 成功 | 成功 | 成功 |
| libc `readdir` | parent 中可枚举 | parent 中可枚举 | parent 中可枚举 |
| raw `getdents64` | parent 中可枚举 | parent 中可枚举 | parent 中可枚举 |

`./hidden`、`sub/../hidden` 和 `chdir` 后相对打开均成功，说明后续 backend
测试必须覆盖规范化、相对 dirfd 和 symlink alias，不能只匹配绝对路径字符串。

设备对 `openat2(2)` 和 `faccessat2(2)` 返回 `ENOSYS`，包括
`RESOLVE_BENEATH | RESOLVE_NO_MAGICLINKS` 用例。该设备上的 production fallback
和 hide backend 均不能把这两个 syscall 当成必备能力。

## 5. Mutation 基线

mutation 只作用于专用沙箱。以下操作成功且真实副作用被探针确认：

| 操作 | 返回 | errno | 基线副作用 |
|---|---:|---:|---|
| `openat(O_CREAT|O_EXCL)` | 0 | 0 | 文件创建成功 |
| `openat(O_TRUNC)` | 0 | 0 | canary 大小变为 0 |
| `mkdirat` | 0 | 0 | 目录创建成功 |
| `unlinkat` | 0 | 0 | canary 被删除 |
| `renameat` | 0 | 0 | canary 被移出 hidden 目录 |
| `linkat` | -1 | 13 (`EACCES`) | 未创建硬链接 |
| 对既有 `hidden` 执行 `mkdirat` | -1 | 17 (`EEXIST`) | 无副作用 |

探针在每个破坏性用例之间恢复 canary，并在结束时仅删除自己创建的固定 fixture。
`linkat` 的 `EACCES` 是 shell-domain/底层策略基线，不是 setup error；后续 App
runner 必须独立记录其结果，不能假定与 shell domain 相同。

## 6. 真实观察路径

下列路径仅执行只读观察：

```text
/storage/emulated/0/Pictures/Nagram
/storage/emulated/0/DCIM/Screenshots
```

两者在 shell domain 下均满足：

- `stat/lstat/access/open/opendir/fstatat/statx/faccessat/openat` 成功；
- parent 的 libc `readdir` 和 raw `getdents64` 均包含目标 basename；
- `openat2/faccessat2` 因内核不支持而返回 `ENOSYS`。

这只建立“无 hide backend 时可见”的对照组，不代表 LocalSend 的 UID、SELinux
domain、mount namespace 或 MediaProvider 视图。

`/proc/self/mountstats`，三者均为 `side_effect=false`。记录到的末次字节数分别为
257074、156488 和 144178。
